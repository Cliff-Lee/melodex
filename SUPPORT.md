# Support

Before filing an issue, check:

- `docs/START_HERE.md`
- `docs/FAQ.md`
- `docs/TROUBLESHOOTING.md`

When reporting a bug include platform, Melodex version, whether the source is Local/User Streams/Jamendo/Internet Archive/third-party, and the smallest reproducible steps. Never paste provider passwords, API keys or Bridge tokens into a public issue.
