# Support

Before filing an issue, check:

- [Start Here](docs/START_HERE.md)
- [FAQ](docs/FAQ.md)
- [Troubleshooting](docs/TROUBLESHOOTING.md)
- [Release status](docs/RELEASE_STATUS.md)
- [Status, stability and trust](docs/developers/00_STATUS_AND_STABILITY.md)

When reporting a bug, include:

- platform/OS;
- Melodex version shown by the build/source you are using;
- whether you built from `main` or installed a packaged release;
- relevant source/provider/extension name;
- the smallest reproducible steps;
- relevant error text with secrets removed.

Never paste provider passwords, API keys, cookies, Bridge/MCP tokens, private keys or private signed media URLs into a public issue.

For security-sensitive reports, follow [SECURITY.md](SECURITY.md).
