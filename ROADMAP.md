# Roadmap

## v0.2 public preview

- macOS, Windows and Linux desktop builds
- Android Provider Bridge client
- Local Files and User Streams
- Jamendo reference provider
- official Internet Archive provider
- MPP v1 / Provider SDK v0.2
- Playback Gateway
- Universal Resolver, Resolver Inspector and match memory
- XSPF/M3U/M3U8 playlist interchange
- Flow, Play for Me, taste memory and Moments
- Rich Now Playing metadata and local lyrics
- optional LLM/MCP control
- credential/private-path redaction for external control

## Next

- signed provider packages and richer permission UI
- Navidrome and Jellyfin first-party legal providers
- improved local-library indexing and artwork cache
- faster provider startup and better progress feedback
- more reliable phrase/beat-grid analysis
- transition preview UI
- Android queue, Flow commands and taste sync through Bridge
- optional encrypted multi-device state sync

## Later

- provider directory with review/signing metadata
- iOS client through Provider Bridge
- desktop stem-assisted transitions where hardware permits
