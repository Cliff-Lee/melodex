# Code of Conduct

## Our standard

Be respectful, constructive, and specific. Debate technical ideas without attacking people. Assume good faith while still taking security, privacy, authorization, and user safety seriously.

Unacceptable behavior includes harassment, threats, discriminatory abuse, doxxing, deliberately publishing secrets, or using project spaces to facilitate unlawful access to third-party systems or media.

## Enforcement

Project maintainers may edit, hide, reject, lock, or remove contributions or participation that violate this standard. Serious security issues should be reported privately using the process in `SECURITY.md`.
