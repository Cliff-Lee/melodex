# Public Domain Lyrics Example

A deliberately small Melodex `lyrics.lookup` reference extension.

It exists to exercise the lyrics contract **without** making a project-maintained example depend on a modern commercial lyrics catalogue or ambiguous redistribution rights. The bundled corpus contains only short historical/public-domain examples.

Try:

- `Auld Lang Syne`
- `Twinkle Twinkle Little Star`

The plugin demonstrates plain lyrics, language/kind filtering, exact normalized title matching, per-entry provenance and rights notes, and persistent caching for immutable bundled data.

It is a developer example, not a comprehensive lyrics service.
