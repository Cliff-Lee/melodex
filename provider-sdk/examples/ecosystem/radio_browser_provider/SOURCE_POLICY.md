# Source Policy — Radio Browser

**Last reviewed:** 2026-09-28

Primary API documentation:

- https://api.radio-browser.info/
- https://docs.radio-browser.info/

Radio Browser describes its API as free/open source and permits use in free and non-free software.

The project asks clients to:

- discover available servers rather than permanently depend on one mirror;
- send a descriptive User-Agent;
- use the station-click endpoint when a user selects/plays a station.

The reference provider follows those behaviors.

## Station content

Radio Browser indexes station-provided stream URLs.

The API/project's openness does **not** mean Melodex owns or relicenses the programming transmitted by individual radio stations.

This provider therefore exposes live playback but does not claim redistribution/offline rights for station programming.
