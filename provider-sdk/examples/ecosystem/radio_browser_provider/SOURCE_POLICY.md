# Source Policy — Radio Browser

API: https://api.radio-browser.info/

The API documentation describes the API as free/open source and permits use in
free and non-free software.

The project asks clients to:

- discover available servers rather than permanently depend on one mirror;
- send a descriptive User-Agent;
- use the `/json/url/{stationuuid}` endpoint when a user selects a station.

This plugin indexes station-provided streams; it does not claim ownership or
redistribution rights over station programming.
