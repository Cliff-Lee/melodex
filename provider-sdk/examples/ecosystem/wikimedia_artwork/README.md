# Wikimedia Commons Artwork Example

Experimental extension implementing:

```text
artwork.lookup
```

The key lesson is **not** merely how to fetch an image.

It shows why Melodex should preserve:

- file source page;
- author/credit;
- per-file licence;
- dimensions/MIME type;
- confidence/provenance.

Wikimedia Commons content has per-file terms. The plugin never turns that into a
blanket "public domain" claim.
