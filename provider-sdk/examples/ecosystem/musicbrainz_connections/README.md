# MusicBrainz Song Connections

A Melodex v0.1 `context.lookup` extension that turns MusicBrainz relationship data into human-readable context cards.

It focuses on connections that are easy to miss in an ordinary player:

- samples and sampled-by relationships;
- remixes, edits, DJ mixes, mash-ups and alternate versions;
- linked compositions/works;
- recording places when MusicBrainz has them.

The plugin requires a MusicBrainz recording MBID. It does not scrape audio or copyrighted liner-note text.
