# Forgotten Favourites

A fully local `library.suggest` plugin for rediscovery.

The plugin ranks tracks using Melodex's coarse private taste signals:

- loves and keeps;
- completion rate;
- play history;
- skips / explicit dislikes;
- time since the last play.

It is intentionally different from “most played”. The spacing curve gives strong tracks a chance to return after they have been absent long enough to feel fresh again.
