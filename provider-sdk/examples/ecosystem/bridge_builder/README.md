# Bridge Builder

A fully local `library.suggest` plugin that finds a track to place between two local tracks.

It uses host-supplied Flow features to look for candidates that make both sides of the transition more coherent:

- tempo compatibility;
- harmonic compatibility;
- energy continuity;
- timbral proximity;
- intro/outro mixability.

This is not an automatic DJ claim. It is an explainable shortlist of possible musical bridges that the user can preview, queue or ignore.
