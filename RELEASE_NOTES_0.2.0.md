# Melodex 0.2.0

**Don't shuffle. Flow.**

v0.2 turns the source-neutral public preview into a much more complete multi-source player and provider platform.

## Highlights

- Built-in **User Streams**.
- Official optional **Internet Archive** provider.
- **Provider SDK v0.2.0** and Playback Gateway.
- **Universal Resolver** with Resolver Inspector and match memory.
- **XSPF/M3U/M3U8** source-neutral playlist interchange.
- **Rich Now Playing** metadata and local lyrics.
- Optional **MCP/OpenWebUI** control.
- **Linux x86_64 AppImage** build.
- Playback-secret/private-path redaction.
- Packaged-app Python provider runner.
- New User and Power User manuals.

## Platform targets

- macOS Apple Silicon DMG
- macOS Intel DMG
- Windows x64 installer
- Windows portable ZIP
- Linux x86_64 AppImage
- Android preview APK/AAB
- source ZIP

## Android

Android remains a preview Provider Bridge client rather than a full standalone desktop-equivalent player.

## Security

Headers, cookies, refresh/access tokens, signed stream URLs and local paths are redacted from LLM/control status responses.

Third-party providers remain executable software. Install only providers you trust.
