# Internet Archive Audio for Melodex

Search public Internet Archive audio items and play a directly accessible audio file from the selected item.

Version 0.1.2 keeps search lightweight: Melodex no longer downloads full item metadata for every search result. File metadata is fetched only when a result is opened or played.

Try searching for `old time radio`, `field recordings`, `netlabels`, `oral history`, `live recordings`, or an artist/title.

Internet Archive is a repository rather than a single licence. Check each item's page for rights and licence information before reuse or redistribution.

Version 0.1.2 also permits Internet Archive's regional `*.archive.org` media CDN hosts so redirected playback remains valid through Melodex's secure playback gateway.
