# Source policy — 24-7 Niche Radio

This provider does not copy, host, download, or redistribute station audio.

Discovery metadata is obtained from the public Radio Browser community directory. Playback resolves the station URL supplied by Radio Browser and connects the user directly to that stream.

The provider only accepts directory records associated with the `24-7nicheradio.com` network domain. Station availability, programming, stream rights, geographic restrictions, and upstream terms remain controlled by the station/network and may change independently of Melodex.

Offline download is disabled.
