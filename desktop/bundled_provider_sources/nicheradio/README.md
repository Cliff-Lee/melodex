# 24-7 Niche Radio provider

A bundled Melodex source for the 24-7 Niche Radio network.

The provider uses the open Radio Browser directory for live station discovery and stream resolution, then restricts results to stations whose homepage belongs to `24-7nicheradio.com`.

Capabilities:

- search live Niche Radio stations by station name, genre/tag, country or language;
- resolve a selected station to its current live stream;
- preserve station artwork and directory metadata where available.

Offline downloads are intentionally disabled because these are live radio streams.

No account or API key is required.
