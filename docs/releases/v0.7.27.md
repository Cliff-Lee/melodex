# Melodex v0.7.27 — Predictive Playback

This release completes P24, preparing the next queued source before it is needed so sequential playback can move with less avoidable waiting on NAS and network sources.

## Playback continuity

- Resolve only the immediate next queue item on the bounded background prefetch lane while the current track continues.
- Prime the source silently on the inactive media deck until it has playable buffer data or a short time limit, then pause at the start. Reuse it for manual next, natural end, or the existing Journey crossfade.
- Discard a prepared source when the queue changes, playback is paused or stopped, or the listener seeks.
- Keep the active track in control if prefetch is rejected or fails; the existing playback load and recovery path remains the fallback.
- Add metadata-free diagnostics for prefetch requests, readiness, use, stale results, failures, cancellations, and preparation time.

P24 adds no controls, whole-track downloads, cloud dependency, or persistent stream URLs. Native iPhone support remains deferred. Physical slow-NAS timing comparison remains owner follow-up.
