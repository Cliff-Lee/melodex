# Melodex v0.7.3

## NicheDB Radio

- Adds **NicheDB Radio** as a bundled source on fresh desktop installs.
- Searches NicheDB's daily-refreshed internet-radio catalogue and plays the station stream directly.
- Filters stations NicheDB currently marks offline.
- Supports normal station search plus:
  - `popular`
  - `genre:ambient`
  - `country:gb`
  - `lang:english`
  - `codec:mp3`
- Preserves station artwork, genres, country/language, codec, bitrate, votes/listens and coordinates where available.
- No account or API key is required for normal use. An optional NicheDB API key can be stored through Melodex's secure source settings for a higher API allowance.
- Offline downloading remains disabled for live radio streams.

## Large-library reliability

- Library scanning now runs away from the main UI thread so large imports no longer have to freeze the application window.
- Scan progress is visible and can be paused or cancelled.
- Scan timing/diagnostic instrumentation makes large-library bottlenecks easier to reproduce and measure.
- A persistent SQLite metadata index lets Melodex reopen a previously scanned library without rereading every audio file.
- Cached library metadata can remain available when a configured music root is temporarily offline or disconnected.
- Index persistence and root changes include regression coverage designed for large collections, including the 12,700-track benchmark path.

## Beta testing and documentation

- Adds a clearer public beta tester path and dedicated tester-feedback issue form.
- Adds GitHub Discussion templates for open-ended feedback and ideas.
- Reorganises the documentation around simple-user, tinkerer and developer entry points.

## Included sources

Fresh desktop installs now include seven bundled provider packages:

- Internet Archive Audio
- LibriVox
- NicheDB Radio
- Radio Browser
- SomaFM
- Wikimedia Commons Audio
- ccMixter
