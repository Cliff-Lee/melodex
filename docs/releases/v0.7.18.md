# Melodex v0.7.18 — P14 tester release

**Status:** prerelease candidate for controlled testing (`v0.7.18-rc.1`).

This candidate adds P14 Zero-to-Discovery improvements on top of the P13
player-first path. Melodex can offer a useful breadth-spaced first session from
the tracks currently available, then refine only the unplayed queue tail from
listening history. Background discoveries can extend a provisional queue while
preserving the listener's current queue intent.

## What to test

1. Start from a clean profile, add a local folder, and choose **Play Something**
   as soon as tracks appear. Confirm playback can begin while indexing continues.
2. Try a small, mixed, duplicate-heavy, single-artist, and poorly tagged library.
   Check whether the first few choices feel varied without losing early tracks.
3. While a scan is active, start playback, then edit the queue. Confirm new scan
   batches do not override the queue you chose.
4. On a returning profile, start **Play something** and confirm playback begins
   before history-based session refinement finishes. Change the queue during
   refinement and confirm your changes remain intact.
5. Export redacted first-music diagnostics and report whether audio was audible,
   not only whether the playback position advanced.

## Qualification status

The deterministic first-session quality and queue-handoff checks pass. The P14
journey harness deliberately separates synthetic queue quality from real
time-to-first-audio. This workspace could not run the Qt test suite because
PySide6 and pytest are unavailable. The tagged release workflow runs the Qt
suite and repository release gates before distribution builds.

Physical local-audio and healthy/slow/offline NAS journeys remain to be confirmed
on tester machines. The diagnostics audio event is a playback-position proxy; it
does not confirm that sound reached speakers or headphones. Do not treat this
candidate as proof that the full P14 latency contract has passed.

## Send back results

Include operating system, clean install or upgrade, approximate library size,
local or NAS source, what you clicked, elapsed time to audible sound, and any
queue change or interruption. Attach **Sources → Export redacted diagnostics…**
when possible.
