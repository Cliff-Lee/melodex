# Melodex v0.7.4

## Hotfixes

- Fixes the **Sources & plugins** crash that could show `name 'QColor' is not defined` after installing or refreshing a provider.
- Updates **NicheDB Radio to 0.1.2**.
- NicheDB Radio now uses Melodex's packaged `requests`/`certifi` HTTPS stack instead of Python `urllib`, fixing certificate-chain failures seen in packaged macOS builds.
- Keeps normal NicheDB use keyless: no account or API key is required.
- Adds regression coverage for the NicheDB HTTPS request path and release guards that prevent the obsolete 0.1.0 provider bundle from shipping again.

## NicheDB Radio

Search remains available through **Explore → Search everything**, including normal station searches and:

- `popular`
- `genre:ambient`
- `country:gb`
- `lang:english`
- `codec:mp3`

Playback still connects directly to the station stream supplied by NicheDB; offline downloads remain disabled for live radio.
