# Melodex v0.7.8

## Crash hotfix

This release is a focused stability update following v0.7.7.

### Fixed: macOS / PySide queued-callback crash

A macOS crash report from an Apple Silicon build showed an `EXC_BAD_ACCESS`
segmentation fault on the Qt main thread inside Shiboken/PySide while Qt was
delivering a posted event to a Python-backed `QObject`.

Melodex's asynchronous helper created a temporary `QObject` signal bridge for
every background task and only retained the most recently created bridge. Under
the higher background concurrency introduced by the Fluid performance work, an
older bridge could lose its final Python reference while Qt still had a queued
completion event waiting for the GUI thread.

v0.7.8 changes that design:

- all background completions now marshal through one long-lived
  QApplication-owned UI dispatcher;
- late completions after shutdown are discarded through a plain Python shutdown
  gate before touching the MainWindow wrapper;
- the existing stale-result and cancellation semantics are preserved;
- regression tests stress 64 overlapping completions and a worker finishing
  after MainWindow close/delete.

### macOS crash-report version metadata

PyInstaller's generated app bundle previously reported `0.0.0` to macOS even
when the Melodex application version was correct elsewhere.

The macOS build now stamps `Info.plist` from Melodex's canonical `VERSION`:

- `CFBundleShortVersionString` reports the real release version;
- `CFBundleVersion` is a numeric build version;
- development versions such as `0.7.9.dev0` are normalized to a valid macOS
  short version while retaining development-version truth in Melodex itself.

### Validation

The crash fix passed:

- Python 3.11 and 3.12 desktop/provider tests;
- Fluid Melodex release gates;
- 12.7k mixed-workload soak;
- large-library and startup baselines;
- macOS Apple Silicon frozen-app build/startup;
- Windows package build;
- Linux package build and Debian/Ubuntu smoke tests.

macOS Intel validation remains part of the standard release package matrix.
