# Melodex v0.7.19 — Journey Composer

Campaign P15 adds a graphical Journey Composer to Music Map. Listeners can
shape a route visually, using exact track waypoints and semantic directions.

## Journey Composer

- Drag Music Map tracks to choose the start and destination.
- Combine exact track waypoints with semantic directions in an editable route.
- Reorder or remove stages, or begin from a suggested route shape.
- Build routes directly between start and destination without intermediate
  stages.
- Play or queue a built journey with its route intent preserved.

## Validation

The v0.7.19 tester candidate runs the repository release gates and platform
package builds. Physical interaction, playback, and broader tester feedback
remain part of candidate qualification.
