# Melodex v0.7.19 — Journey Composer and Living Queue

Melodex v0.7.19 brings together the graphical Journey Composer from Campaign
15 and the live queue controls from Campaign 16.

## Journey Composer

- Drag tracks on Music Map to choose a start, destination, or exact waypoint.
- Combine track waypoints with musical directions in an editable route.
- Reorder or remove stages, or start from a suggested route shape.
- Build a route directly between its start and destination.
- Play or queue a journey while preserving its route intent.

## Living Queue

- Keep, remove, and reorder upcoming tracks while the current track continues.
- Steer a live journey toward musical qualities, a similar track, an artist, or
  a Music Map area.
- Lock upcoming tracks so automatic replanning preserves them.
- Undo the most recent automatic route change without losing protected choices.
- See a concise explanation for why a suggested track was chosen.

## Automated validation

The release candidate passed the Python 3.11 and 3.12 desktop and provider SDK
test suites, the Fluid Melodex and large-library qualification jobs, and the
desktop, Linux, and Android package build workflows.

Manual active-playback acceptance remains a tester check: start a Journey Live
route, edit and steer its upcoming queue, then confirm audible playback and the
current track remain uninterrupted. The checklist is in
[`P16_LIVING_QUEUE.md`](../P16_LIVING_QUEUE.md).
