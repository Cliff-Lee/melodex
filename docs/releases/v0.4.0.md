# Melodex v0.4.0

Melodex v0.4.0 adds a complete visual listening surface to Now Playing. Each recording gets a stable visual identity, with cached Flow analysis, cover colour, lyrics and local listening context shaping the available views.

## Living Canvas modes

- **Living Canvas** — a gently moving, track-aware scene;
- **Song Fingerprint** — a repeatable sigil for the recording;
- **Musical Journey** — a cached energy contour with click, drag and keyboard seeking;
- **Constellation** — nearby tracks from the queue and local history, which can be inspected and queued;
- **Lyrics Typography** — large local lyrics, synchronized when timing is available and clearly paced as an estimate otherwise;
- **Album World** — a deterministic landscape coloured from the cover art;
- **Sonic Weather** — a plain-language reading of cached tempo, brightness, energy and rhythmic density;
- **Visual Memory** — a local listening atlas grouped by session, album, week or year;
- **Minimal** — a quiet identity and progress view.

## Personal visualizers

The first `.mdxviz` API accepts bounded JSON scene recipes. Install one with **Now Playing → Living Canvas → Install visualizer…**. Recipes are data, not executable code: they cannot access audio, lyrics, the network, local paths, listening history or player controls. The release includes the **Orbit Garden** example and an author guide.

## Performance and privacy

- Visualizers never run FFT work or decode audio during playback. They use cached Flow data only; a track without a cache still gets a stable identity scene.
- Auto mode is capped at 15 fps and reduces drawing detail if a frame is slow. Eco runs at 10 fps, High is capped at 30 fps, and Battery keeps a static scene.
- Continuous animation stops while paused, hidden, minimized or ended. Seeking and normal playback stay on the existing player path.
- Visual Memory and Constellation use bounded local history and queue data. No listening history, lyrics, fingerprints or audio features are uploaded.
