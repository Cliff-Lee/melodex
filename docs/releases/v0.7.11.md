# Melodex v0.7.11

## Humanize Melodex

v0.7.11 is a product-polish release.

The goal was not to remove Melodex's unusual features. It was to make the app feel like a music player first, with deeper tools revealed when they are useful.

### A calmer first run

Fresh installs now foreground the one thing that matters first: adding music and listening.

When there is no local library yet:

- Home focuses on **Add my music** instead of showing listening modes and exploration tools that cannot be used yet;
- **Continue listening** stays hidden until there is actually something to continue;
- My Music hides search, view, rescan, Album Wall, Moments and artwork-maintenance controls until tracks exist;
- Explore hides Album Wall, Music Map and local-intelligence actions until a local collection exists.

Adding music from Home now takes you into My Music so the indexing state is visible where you expect your collection to appear.

### Less explanation, clearer hierarchy

Persistent interface copy has been shortened across Home, Explore, Journeys, Playlists, Sources and listening controls.

Detailed explanations remain available in tooltips and documentation, but the normal interface now says less.

Common page titles, subtitles, section headings and supporting text use a shared visual grammar. Primary, secondary and quiet actions are more clearly distinguished, and common cards/empty states are slightly denser and more consistent.

### AI is optional, not the product identity

Melodex still supports AI-assisted workflows, but v0.7.11 stops foregrounding them.

- ordinary playlist import is now the primary playlist-import action;
- **Paste from AI…** remains available as a secondary action;
- **Ask Melodex…** is no longer part of the default Explore path and follows Power tools;
- first-run screens no longer expose AI/plugin/system concepts before they are relevant.

### Progressive disclosure

Advanced functionality is still there, but it appears later.

- Sources & plugins no longer permanently shows the plugin capability picker;
- **Add features…** reveals plugin categories when requested;
- source-specific actions appear after a source is selected;
- **Check connections** follows Power tools;
- Music Map route planning gives **Find route** the clear primary action, with play/queue as follow-up actions and maintenance controls visually quieter;
- Album Wall maintenance options are de-emphasized rather than removed.

### Sources without the dashboard feel

The Sources & plugins page has been simplified:

- the three summary-card metrics dashboard is gone;
- local-first wording is shorter;
- plugin/source details remain available without dominating the page;
- the v0.7.10 **Export redacted diagnostics…** support path remains directly available for NAS/library/source reports.

### More natural empty and partial states

Several states that previously sounded like internal diagnostics now read as normal product states.

Examples include:

- **No music added yet** instead of a promotional empty-library message;
- clearer no-playable-audio wording;
- simpler local-index saving text;
- **No lyrics found yet** instead of source-matching language;
- generic missing artist/track information instead of exposing provider names such as MusicBrainz in ordinary UI.

### Packaged screenshot audit

The final H6 pass was based on screenshots from the packaged Linux build launched with a clean user profile.

That audit caught issues that code review alone did not: controls appearing before they could be useful, redundant summary cards, and empty-state screens that still looked like feature catalogues.

Those findings drove the final first-run cleanup in this release.

## Relationship to v0.7.10

v0.7.10 remains the NAS resilience release: bounded retry, fail-safe catalog preservation, NAS fault qualification, clearer fallback UX and redacted diagnostics.

v0.7.11 does not replace that work. It sits on top of it and changes how Melodex presents itself to listeners.
