# Melodex v0.7.14

## Responsive playback and smoother album browsing

This release improves how Melodex handles playback changes and keeps the Album Wall responsive while it moves.

### Playback stays under the listener's control

- Seek requests follow the listener's latest intent and reflect the playback backend's acknowledgement.
- End-of-track transitions have one authoritative path, including the final track in an album.
- Transition planning is kept out of the playback timer so a tick does not do extra planning work.
- Album playback preserves the selected album's order and explicit play intent.

### Album Wall motion stays lightweight

- Motion uses an allocation-free paint path and defers refinement until movement settles.
- Artwork uses pre-scaled covers and coalesced motion updates.
- Applying artwork avoids filesystem checks in the interaction path.
- Aggregate Album Wall motion diagnostics are covered by automated contracts.

### Verification

The release workflow validates the version, repository documentation and release gates, then builds the tagged source and platform packages. Physical NAS, device and audio-output acceptance remains in the manual acceptance runbook.
