# Melodex v0.7.5

## Highlights

### More reliable connected sources

- Fixed packaged macOS certificate-chain failures for provider/plugin worker processes by supplying Melodex's bundled trusted CA bundle.
- Search now runs connected sources concurrently, so one slow source no longer holds up all the others.
- A broken or temporarily unavailable source no longer opens repeated blocking warning dialogs or discards results from healthy sources.
- Search now reports source problems inline with friendly statuses such as **Timed out**, **Secure connection failed**, and **Rate limited**.
- The permanent live-provider matrix independently verifies search → resolve → media playback for ccMixter, Wikimedia Commons Audio, Internet Archive Audio, SomaFM, Radio Browser, NicheDB Radio, LibriVox, and optional Openverse Audio.

### Internet Archive Audio 0.1.1

- Reworked Internet Archive search so it performs one lightweight catalogue request instead of downloading full metadata for every candidate.
- Full file metadata is fetched only when a result is opened or played.
- Item metadata is cached within the provider process.
- The provider is now checked in as normal source code and covered by package/source parity and lazy-resolution regression tests.

### Native Lyrics experience

- Lyrics is now a listener-facing Melodex feature rather than exposing plugin-management controls in Now Playing.
- Added a simpler **Source / Refresh lyrics / Full screen / Translate / More** toolbar.
- Synchronized lyrics use clearer current-line emphasis and retain click-to-seek behaviour.
- Local/personal lyrics can be edited while temporary online/plugin lyrics remain non-persistent.
- Online lyric failures no longer overwrite valid local lyrics.

### Album Wall and Music Map polish

- Album Wall now opens at a readable browsing scale with smoother pan/zoom behaviour.
- **Actual size** and **Overview** are explicit navigation actions.
- Music Map defaults to selected relationships instead of rendering the full connection web immediately.
- Spatial pages keep the visual canvas dominant by moving maintenance and journey controls behind compact option menus.

### Large-library reliability

- Incremental rescanning reuses cached tags for unchanged files and only reopens new or modified tracks.
- Library scans run in a disposable worker process so a stuck NAS/SMB filesystem call cannot freeze the main application indefinitely.
- My Music progressively renders large album/artist/track collections instead of constructing thousands of widgets at once.
- Search still covers the complete local collection while off-screen cards are released to reduce memory pressure.

## Provider audit

The v0.7.5 provider audit passed real live search → resolve → media-byte playback for:

- ccMixter
- Wikimedia Commons Audio
- Internet Archive Audio 0.1.1
- SomaFM
- Radio Browser
- NicheDB Radio
- LibriVox
- Openverse Audio

Third-party services can still have temporary outages, but one failing source now degrades independently instead of breaking the whole Explore search experience.
