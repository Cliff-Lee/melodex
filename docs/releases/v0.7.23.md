# Melodex v0.7.23 — Android Companion Polish

This release polishes Melodex's Android companion for listening on a phone and
using it alongside a desktop Provider Bridge.

## Android companion

- Add the supplied Melodex icon for Android launcher sizes, adaptive icons, and
  themed icons on supported devices.
- Apply Melodex's midnight, cyan, and violet colors throughout the app.
- Add a now-playing panel with artwork, track information, playback progress,
  seek, play/pause, restart, and quick access to the local queue.
- Keep playback on each phone independent. Each phone owns its Android player
  and local queue, and pairs separately with the Provider Bridge.
- Expand the Android setup guide with a two-phone check for independent
  playback.

## Device check

After installing, pair two phones with the same Provider Bridge and start a
track on each. Pausing or seeking on one phone should leave playback on the
other phone unchanged. The setup guide includes these steps.
