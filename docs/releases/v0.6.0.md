# Melodex v0.6.0

Melodex v0.6.0 polishes the listening visualisations, restores playlist import from AI chats, and brings six optional desktop music sources back as first-launch bundled providers.

## Now Playing and Living Canvas

- Built-in visualiser scenes have clearer track hierarchy and labels, with a restrained track-colour backdrop.
- The Musical Journey waveform and playback progress now share a seekable control, including mouse, drag and keyboard seeking.
- Visual work stays separate from playback. Scenes use cached Flow data when available and do not analyse audio during playback.

## Paste playlists from AI chats

- Use **Playlists → Paste from AI…** to import a playlist copied from ChatGPT, Claude, Gemini or another AI chat. Melodex does not need an AI connection or API key.
- Paste Melodex JSON, common JSON track lists, Markdown lists or tables, plain text, CSV/TSV, or M3U text. File import also supports JSON, text/CSV, XSPF, M3U and M3U8.
- Copy the suggested prompt, paste clipboard contents, and analyse the playlist. Melodex matches artist/title requests against connected music sources, saves the playlist, queues available matches and keeps unmatched requests for later.
- Pasted text stays in Melodex. When matching is requested, connected music providers receive the corresponding search requests.

## Desktop music sources

Desktop first launch includes these provider packages:

| Source | Provider version |
| --- | ---: |
| ccMixter | 0.1.3 |
| SomaFM | 0.1.1 |
| Radio Browser | 0.1.2 |
| Wikimedia Commons Audio | 0.1.1 |
| LibriVox | 0.1.2 |
| Internet Archive Audio | 0.1.0 |

These packages connect to their respective music sources; the installers do not include audio files. Users can remove bundled providers and restore them later in the advanced source controls. A newer manually installed provider is not replaced by an older bundled copy.

## Responsible use

Melodex is designed for music that the user is authorised to access. Public releases do not ship private credentials, copyrighted media, source-specific bypass logic or access-control circumvention.
