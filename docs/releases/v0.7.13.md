# Melodex v0.7.13

## More dependable lyrics and a stronger visual experience

v0.7.13 fixes several rough edges in Now Playing and gives the visual scenes a more finished, coherent presentation.

### Lyrics stay in sync

- Now Playing and Lyric Flow now share the same canonical lyrics and playback position when fullscreen opens.
- Synced lyrics remain readable in the Now Playing reader.
- Untimed lyrics are shown as complete, unhighlighted text. Melodex no longer guesses which sentence is playing, avoiding misleading line emphasis.
- The fullscreen action now completes reliably.

### Faster track changes

- When moving between tracks by the same artist or album, Melodex immediately reuses artwork and artist details already loaded in the session while track-specific details continue loading.

### Visuals

- **Profile Pulse** has larger, brighter concentric forms.
- **Minimal** uses the current album artwork to make the scene feel distinct for each track.
- **Sonic Weather** layers slow, soft aurora ribbons over an artwork-derived atmosphere.
- **Constellation** gives the current cover a stronger role and reduces idle connector clutter.
- **Memory Atlas** uses cached, soft-edged color fields instead of an axis-and-label chart. Hover a memory to explore its details.
- These scenes remain bounded and inexpensive to render; static Memory Atlas artwork is cached and refreshed when the grouping changes.

### Verification

The change set passed all 20 pull-request checks, including Python 3.11 and 3.12, visual QA captures and performance qualification, macOS and Windows packaging, Linux package smoke tests, and the large-library, NAS, startup, and responsiveness gates.

The release workflow performs the release-specific validation and builds the downloadable packages from this tagged source.
