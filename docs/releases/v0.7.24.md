# Melodex v0.7.24 — Android 16 and Google Play preparation

This release advances the Android companion toward future Google Play testing.
GitHub Releases remain the install path; this release does not publish the app
to Google Play.

## Android

- Target Android 16 (API 36) and compile against API 36.
- Add an in-app link to the Melodex privacy policy and document Android local
  playback, QR pairing, and Provider Bridge data handling.
- Add support for signing an Android App Bundle with an owner-managed Play
  upload key supplied through GitHub Actions secrets. No key is stored in the
  repository.
- Keep Android standalone local playback available with optional Provider
  Bridge connectivity.
- Set Android versionCode to 724.

## Install and Play Console status

Install Melodex with the attached APK. The Android App Bundle in this GitHub
release is unsigned because no Play upload key has been configured, so it
cannot be uploaded to Play Console yet. The upload-signing setup is documented
in the P21 campaign notes.

## Device checks

On Android 16, check local playback, background controls, QR pairing, and the
privacy-policy link. A tablet or foldable check is also useful. iPhone support
remains deferred.
