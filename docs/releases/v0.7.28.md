# Melodex v0.7.28 — Music Map 2.0

A map-first listening experience for the music you already own, available as a **public beta** across macOS, Windows and Linux. The Music Map remains an exploration surface rather than an additional music player or a new subscription service.

## Explore visually
- Explore album-art regions instead of a dense wall of covers. Overview clusters show a count, artist-grounded label and their own ▶ listening action; click the artwork to zoom into the real mapped tracks.
- Back/Forward, find the currently playing track, search and Explore nearby help you browse without accidentally changing playback. Only genuine sonic or local knowledge-graph evidence is used for nearby suggestions.
- View, More and Journey controls float above the map, preserving the usable map viewport, including compact-window layouts.

## Start listening from the map
- **Play** and **Queue** remain direct track actions.
- **Play from here** builds a Mind + Flow session seeded by the selected track.
- **Surprise me** builds an exploratory listening session using existing preferences.
- **▶ Play region** limits the listening candidates to locally available tracks actually mapped to that region.
- **Plan a journey** lets you select start and destination by clicking on the map. Preview the Pathfinder route, then explicitly Play or Queue it. Routes are calculated in the background, with stale requests discarded and the **actual playing step** highlighted during playback.

## Quality and compatibility
- Synthetic 700-track route-preparation p95 remains under the 100 ms CI budget; note that longer Pathfinder computation takes place in the background.
- Frozen-executable GUI tests passed on macOS Apple Silicon and Intel, Windows x64, Ubuntu 22.04/24.04/26.04 and Debian 12. These tests check navigation, mapped route interaction, screenshots and clean Qt shutdown; they are **not real-audio or NAS listening tests**.
- Built on the existing local-first Melodex player, library indexer and playback engine. Existing P24 predictive playback remains included.

## Download and install

Get the current stable installer from **[Melodex Releases](https://github.com/Cliff-Lee/melodex/releases/tag/v0.7.28)**:

- macOS Apple Silicon: `Melodex-macOS-arm64.dmg`
- macOS Intel: `Melodex-macOS-intel.dmg`
- Windows: `Melodex-Windows-x64-Setup.exe` or `Melodex-Windows-portable.zip`
- Linux: `Melodex-linux-x86_64.deb` or `Melodex-linux-x86_64.AppImage`
- Android: `Melodex-Android.apk`; its Music Map 2.0 desktop interface is **not** an Android feature.

On macOS the GitHub beta build may be unsigned or not Apple-notarized. If macOS blocks the launch, follow the [official Mac installation and Gatekeeper instructions](../INSTALL_MACOS.md); only allow a copy downloaded from the project's official GitHub Releases page.

## Public beta limitations

The MM2 features passed automated tests with synthetic music; **real-library/NAS playback and accessibility across every setup are not yet fully hardware-qualified**. Some large or inaccessible music sources may require extra waiting or reconnection. Please report playback, artwork, installer or window-layout problems via [GitHub Issues](https://github.com/Cliff-Lee/melodex/issues) with your platform, package type and steps to reproduce. Do not include private paths, account tokens or your actual music files.

iPhone support remains deferred. Android Play Store publication is separate from distributing the installable APK on GitHub.
