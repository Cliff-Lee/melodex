# Melodex v0.7.0

Melodex v0.7.0 is a major desktop experience update. It introduces the visual **Album Wall**, reorganises the application around listener goals, and turns **My Music** into a richer collection browser with persistent artwork, visual artist/track views and safe local metadata correction.

## A simpler desktop

The primary desktop navigation is now organised around what a listener is trying to do:

- **Home**
- **My Music**
- **Explore**
- **Journeys**
- **Playlists**
- **Sources & plugins**

Advanced provider, routing and diagnostic controls remain available through **Power tools** rather than occupying the default interface.

Home is intention-led: **Play something**, **Comfort**, **Explore**, **Rediscover**, **Continue listening**, and visual exploration entry points.

The persistent player now acts as the route into **Now Playing**, where artwork/details lead and optional visualisations live under **Visuals**.

## My Music becomes a visual collection

**Albums** is now the default collection view, using a responsive artwork grid rather than a plain track list.

New collection behavior includes:

- visual **Albums**, **Artists** and **Tracks** views;
- artist cards with cached artist photos or representative album artwork;
- track rows with their album artwork;
- album/artist/track search;
- direct album, artist and track playback;
- queue actions from the collection;
- visible **Needs artist** guidance for incomplete metadata.

### Persistent artwork

**Find missing artwork** now remembers the association between a downloaded image and the album it belongs to.

Once Melodex finds a cover, it remains available after navigating away, rebuilding the page or restarting the application.

Artwork lookup remains explicit. Simply opening My Music does not launch a bulk network lookup.

Artist photos use the same remembered-cache principle.

### Safe metadata correction

Local tracks can now be corrected directly in Melodex.

Editable fields include artist, title, album, album artist, year and genre.

Corrections:

- survive rescans;
- immediately improve library grouping and browsing;
- are stored by Melodex;
- **do not rewrite the original audio file or embedded tags**;
- can be removed with **Use file tags again**.

Metadata lookup also handles **Unknown artist** more intelligently by using available title/album information rather than querying for an artist literally named "Unknown artist".

### Better compilation grouping

Album Artist metadata now has stronger authority, and conservative repair logic helps reunite obvious tribute albums, compilations and soundtracks that would otherwise be split into many one-track albums.

## Album Wall

The new **Album Wall** turns a local collection into a stable visual place built from record covers.

Albums can be arranged by:

- **Sound**
- **Familiarity**
- **Time**
- deterministic **A-Z shelves**

Sound placement reuses cached Flow analysis. Unanalysed albums remain visible at stable fallback positions.

The wall supports pan/zoom, search, current-album highlighting and direct album playback/queueing.

## Explore and Music Map

A new **Explore** hub presents three clear routes:

- **Search everything**
- **Album Wall**
- **Music Map**

Music Map now uses progressive disclosure. Normal browsing/playback stays simple; route planning, journey shaping and live steering appear only when requested or when Power tools is enabled.

## Sources, Journeys and Playlists

Sources are shown as friendly status cards with one relevant setup action. Provider priority, diagnostics, bridges, manual installation and removal remain available to power users.

Journeys, Playlists and Moments now have instructional empty states rather than large unexplained blank panels.

**Paste from AI** remains a first-class playlist workflow and does not require connecting an AI account.

## Interaction polish

- explanatory hover help describes consequences instead of repeating button labels;
- Ctrl/Cmd+K opens an expert command palette;
- clearer transport controls and playback feedback;
- quieter scrollbars/tabs/status chrome;
- persistent Power tools preference;
- responsive visual collection layouts;
- artist/track surfaces are built lazily to avoid slowing large libraries.

## Privacy

Melodex remains local-first.

- Local collection scanning stays on the device.
- Audio is not uploaded for collection browsing.
- Flow/local analysis remains local.
- Metadata corrections are stored locally rather than written into audio files.
- Online artwork/artist lookup happens only through explicit actions or other documented enrichment operations.

## Responsible use

Melodex is designed for music that the user is authorised to access. External music, artwork, lyrics and metadata retain their original licences and rights. Public releases do not include private credentials or access-control circumvention.
