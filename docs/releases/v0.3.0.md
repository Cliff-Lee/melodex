# Melodex v0.3.0

Melodex v0.3.0 is the first release after the large source-neutral ecosystem and trust-hardening campaign.

It updates the public desktop and Android distributions so they match the current repository rather than the older v0.2.0 snapshot.

## Highlights

### A much broader source-neutral platform

- Universal multi-source resolver and resolver inspection.
- Built-in User Streams source.
- Provider SDK and MPP provider workflow for independently developed music sources.
- Provider Bridge for controlled LAN access from the Android client.
- Legal/open reference integrations and provider examples.

### Capability extensions

Melodex now supports installable `.mdxplugin` capability extensions through the Capability Broker.

Current experimental v0.1 capability contracts include:

- identity;
- metadata;
- artwork;
- lyrics.

This allows playback, identity, artwork and metadata to come from different extensions while retaining provenance.

### Plugin Directory and registry

The desktop app includes a registry-backed Plugin Directory with:

- HTTPS package distribution;
- package byte-size and SHA-256 verification;
- package ID/version verification;
- manual-vs-registry installation provenance;
- explicit update detection;
- compatibility and permission metadata;
- append-only registry review records;
- **View review** access from the directory.

A registry-verified install means the installed bytes and package identity match registry metadata. It is not cryptographic publisher identity.

### Plugin configuration and runtime trust

Third-party providers and capability extensions can now declare configuration fields.

Melodex:

- brokers only declared configuration values to the plugin;
- stores secret values in the operating-system credential store when available;
- falls back to session-only secret storage rather than plaintext JSON;
- scrubs third-party child-process environments;
- tracks extension health and redacted error categories;
- applies the provider playback-host allowlist to HTTP(S) playback resources and redirects.

These controls reduce accidental exposure and improve isolation, but third-party plugin processes are **not** a complete operating-system sandbox.

### Redacted diagnostics

Desktop Melodex now provides:

```text
Sources
→ Show power tools
→ Export diagnostics…
```

The export is designed for support reports while omitting plugin configuration values, credentials, local-library paths, stream/playback URLs, request headers, cookies and track titles.

### Developer ecosystem

The repository now includes a clearer contributor and extension-development path:

- 5-minute developer quickstart;
- provider and enrichment tutorials;
- Provider SDK tooling;
- registry validation and review-history tooling;
- REST/OpenAPI documentation;
- MCP and OpenAI function-tool integration;
- first-contribution guide;
- Code of Conduct and support workflow;
- stronger documentation, terminology and release checks in CI.

## Versioning

This release uses:

```text
Melodex application: 0.3.0
Provider SDK:        0.6.0
MPP protocol:        1.0 preview
Capability contracts: experimental v0.1
```

These are separate versioning systems.

## Release/version correctness

v0.3.0 also fixes the release-metadata problem documented for v0.2.0.

For this release, CI requires:

```text
Git tag
==
VERSION
==
desktop package version
==
Python app version
==
Windows installer version
==
Android versionName
```

Android `versionCode` is deterministically derived from the app version.
