# P14b — Published package smoke

P14b verifies the **actual files attached to the public v0.7.12 GitHub
Release**, not fresh packages built from source.

That distinction matters: P14a proved release identity and hashes. P14b checks
that the published packages can be downloaded, opened/installed and launched on
their native operating systems.

## What is tested

### macOS Apple Silicon

- downloads `Melodex-macOS-arm64.dmg` from the public release;
- verifies its SHA-256 against the P14a manifest;
- mounts the downloaded DMG;
- launches the executable inside `Melodex.app`;
- requires the full packaged startup trace through the first Qt event-loop turn.

### macOS Intel

The same flow is run natively on the Intel macOS runner against
`Melodex-macOS-intel.dmg`.

### Windows

- downloads the published portable ZIP and Inno Setup installer;
- verifies both hashes;
- extracts and launches the portable build;
- silently installs the published installer into a clean temporary directory;
- launches that installed application;
- requires a complete packaged startup trace from both paths.

### Linux

- downloads the published `.deb` and AppImage;
- verifies both hashes;
- installs the downloaded `.deb`;
- launches the installed application;
- launches the downloaded AppImage with its FUSE-less CI path;
- runs the normal packaged GUI smoke check plus complete startup traces.

### Android package integrity

The Android job downloads the published APK and AAB, verifies both hashes and
ZIP integrity, and confirms the APK reports:

- package `com.melodex.app`;
- version code `712`;
- version name `0.7.12`.

This campaign intentionally does not turn Android into a desktop-equivalent
runtime test. Deeper Android standalone behaviour belongs to the Android
campaign.

## Evidence

`.github/workflows/postrelease-package-smoke.yml` is intentionally reusable via
manual dispatch for a published release tag.

`scripts/postrelease_package_smoke.py` contains the cross-platform harness and
writes JSON evidence for each runner.

## Completion gate

P14b is complete only when the published-release smoke workflow is green for:

- macOS Apple Silicon;
- macOS Intel;
- Windows portable;
- Windows installer;
- Linux deb;
- Linux AppImage;
- Android APK/AAB package integrity.

A failure is treated as a package/release defect and fixed before moving to
P14c.
