# Melodex v0.7.20 — Rediscovery and Private Taste

This release brings the P17 Rediscovery Engine and P18 Private Taste Engine
into the stable desktop and Android Bridge-client builds.

## Rediscovery

- Resurface forgotten favourites and unplayed tracks from artists a listener
  already enjoys.
- Find hidden album tracks using local listening history and album metadata.
- Replay a Memory Atlas session, album, week, or year in its recorded order,
  with each replay bounded to 200 tracks.
- Use the same local rediscovery signals in Music Map, journeys, Living Queue,
  and replay explanations.

## Private taste

- Separate durable preferences, recent listening reactions, and the amount of
  exploration requested for a session.
- Correct the model directly with **More like this**, **Less like this**, and
  **Clear taste correction**.
- Apply bounded, explainable taste adjustments to local listening surfaces
  while preserving explicit track dislikes and cold-start playback.
- Keep profile and session context on-device; do not add the new model layers to
  provider snapshots or external AI requests.

## Android

The Android package in this release remains the Provider Bridge client.
Standalone phone-library playback is not included in v0.7.20.

## Packages

The release workflow attaches the installable Android APK, Android App Bundle,
macOS and Windows packages, Linux packages, and source archive after their
platform build and smoke checks complete.
