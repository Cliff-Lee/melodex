# Melodex v0.7.29 — macOS startup hotfix

This maintenance release fixes a macOS startup crash introduced in v0.7.28.

## Fixed

- Guard the early Qt `WindowStateChange` callback during window geometry restoration, before the playback feature is initialized. This prevents the `AttributeError: 'MainWindow' object has no attribute 'playback_feature'` crash on launch.
- Add a regression test for window-state events occurring during startup geometry restoration.

## Testing

- Mac owners: replace v0.7.28 with the v0.7.29 installer appropriate for Apple Silicon or Intel, open Melodex, and confirm it reaches the main window and can start playback.
- Automated tests and packaged startup checks must complete successfully before considering the release verified.

## Installation

Download the correct macOS `.dmg` asset from this release. If macOS blocks the unsigned application, use Finder's **Open** context action and follow the macOS security prompt. Only bypass the warning if you obtained the installer directly from this project's official GitHub release.
