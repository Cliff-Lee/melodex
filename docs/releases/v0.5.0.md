# Melodex v0.5.0

Melodex v0.5.0 adds first-party Linux release packages, built and checked on an Ubuntu 22.04 baseline.

## Linux downloads

- `Melodex-linux-x86_64.deb` for Ubuntu 22.04/24.04/26.04 and Debian 12 on x86_64.
- `Melodex-linux-x86_64.AppImage` for glibc-based Linux desktop systems on x86_64. Ubuntu 22.04/24.04/26.04 and Debian 12 are smoke-tested; other distributions are not yet verified.

Both packages include Melodex, Python, Qt and Qt Multimedia. The `.deb` declares host graphics and audio dependencies and integrates with the desktop application menu. FFmpeg remains optional for deeper local Flow analysis.

For install steps and current compatibility limits, see the [Linux installation guide](../INSTALL_LINUX.md).

macOS, Windows and Android artifacts continue to be built by their existing release workflows.
