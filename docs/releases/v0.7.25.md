# Melodex v0.7.25 — Playback recovery and session restoration

This release completes P22, focused on keeping playback recoverable through track, storage, network, output-route, and app-process failures.

## Playback recovery

- Keep an incoming-deck failure from interrupting the active track.
- Bound transient remote-source retries and local storage recovery; discard stale recovery results after playback changes.
- Rebind desktop playback to the current output after route changes or app reactivation, preserving explicit pause and stop intent.
- Persist desktop queue identity and position with sensitive stream data removed. Restore sessions paused and resolve provider identities again when playback resumes.
- Save Android local MediaStore queue position and restore the service session paused.

## Qualification

P22f records automated fault-injection coverage and its limits in the P22 campaign notes. Release CI covers desktop tests and Linux, macOS arm64 and Intel, Windows x64, and Android package builds. Device-level Android Bluetooth, audio-focus, and playback-service restart checks remain later owner testing.

## Distribution

Installable builds are distributed through GitHub Releases. Android App Bundle signing uses the owner-managed upload-key secrets when configured; this release does not publish to Google Play. Native iPhone support remains deferred.
