# Melodex v0.7.12 release integrity

P14a verifies that the published v0.7.12 release is the release we intended to
ship. It is deliberately limited to identity, completeness and packaging
evidence; packaged-app UX and real-device behaviour belong to P14b.

## Result

**PASS**

The public GitHub release, git tag, release commit, version metadata, uploaded
assets and release-distribution workflows agree.

## Follow-up deliberately outside P14a

The packaged startup measurements show enough runner-to-runner/platform variance
that P14b should test the **actual downloaded v0.7.12 application** on real
hardware, especially macOS Apple Silicon. That is a runtime/UX qualification
question, not a release-identity defect.

P14a is complete when this report and checksum manifest are merged with their
normal repository checks green.
