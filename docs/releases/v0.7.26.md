# Melodex v0.7.26 — Unified Android and Desktop Listening

This release completes P23, bringing Android local playback and the desktop Provider Bridge together as one local-first listening experience.

## Android companion

- Browse the desktop’s local library and search connected music sources from a QR-paired phone.
- Mix phone-local and Bridge tracks in one phone-owned queue. Bridge tracks resolve by stable provider-qualified IDs when playback starts.
- View the desktop’s current track, playback state, and queue from Android.
- Move the active session between phone and desktop only when requested. Independent phones keep separate playback and queues.
- Continue using the phone’s local player and queue when the desktop is unavailable.

## Security and network access

- The desktop Bridge starts on loopback. Sharing it on the local network requires explicit confirmation and can be disabled again.
- Each phone has its own revocable token. Pairing codes are short-lived and single-use; paired tokens are stored as hashes with private file permissions.
- Control and library routes require a bearer token. Query-string tokens are limited to direct media streaming.

## Distribution

Android APK and AAB builds, desktop installers, and Linux packages are distributed through GitHub Releases. Physical Android playback, process restart, Bluetooth/audio focus, LAN handoff, changed-address recovery, and browse/queue accuracy remain owner device checks. Native iPhone support and Google Play publication remain deferred.
