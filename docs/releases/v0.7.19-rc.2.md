# Melodex v0.7.19-rc.2 — P15 Journey Composer tester release

This candidate builds on the P14 Zero-to-Discovery tester release and adds the
P15 Journey Composer. Journey shaping is now a direct graphical route: drag
tracks to choose the start and destination, add semantic directions, and place
exact track waypoints in sequence.

## What to test

1. Open **Music Map → Plan a route… → Journey options… → Compose**.
2. Drag a Music Map track to **Start** or **Destination**. Try clicking an
   endpoint after selecting a track as well.
3. Click a direction to append it, then drag directions and tracks into the
   timeline. Reorder stages by dragging; also try **Move up**, **Move down**,
   and Delete.
4. Load each **Starting shape**, edit its stages, and build the journey.
5. Clear all stages and build a direct Start-to-Destination route.
6. Try **Play** and **Queue** on a built route. Confirm the result follows exact
   track waypoints and explains semantic stages.

Report your operating system, approximate library size, what you tried, and any
unexpected route or interaction. A small local Music Map is enough to test the
composer; larger libraries are useful for checking that route tools remain
responsive.

## Qualification status

Focused journey, workspace, recipe, persistence, replay, and Music Map tests pass
locally. The release candidate workflow runs the full repository gates before
building platform installers. Physical interaction and playback should still be
confirmed on tester machines.
