# Melodex v0.7.22 — Android Playback Continuity

This release expands Android from the first local playback preview into a
standalone player with optional connections to another Melodex installation.

## Android on this phone

- Play audio indexed on the phone without a computer or Provider Bridge.
- Keep playback running in the MediaSession foreground service with media
  notification, lock-screen, audio-focus, and headset controls.
- Search and sort the local library, view artwork and track details, and manage
  a queue that is saved across app restarts.

## Optional Provider Bridge

- Pair Android with a desktop, NAS, or home server by scanning a QR code on the
  same trusted local network. Pairing uses no account or external rendezvous
  service.
- The one-time QR code expires after two minutes. Each phone has its own token,
  which can be revoked from the desktop pairing dialog or from the phone.
- Android stores its saved Bridge credentials encrypted with Android Keystore.
  Manual URL/token entry remains under **Advanced setup**.
- Camera permission is requested only when you choose to scan a QR code.
- Bridge remains optional: phone music works without a desktop, internet
  connection, or Bridge setup.

## Preview notes

The current pairing flow uses a QR code; automatic local-network discovery is
not included yet. Pair only over a trusted local network because the Bridge
uses HTTP on the LAN. See the [Android installation guide](../INSTALL_ANDROID.md)
and [privacy notes](../PRIVACY.md) for setup and data details.

The release workflow checks version consistency and builds the platform packages. Physical-device checks are still useful
for Android permission behavior, QR scanning, reconnect after relaunch, media
revocation, and playback on Android 12-or-older and Android 13-or-newer devices.

## Packages

The release workflow attaches Android APK/AAB, macOS and Windows packages,
Linux packages, and the source archive after platform build and smoke checks
complete.
