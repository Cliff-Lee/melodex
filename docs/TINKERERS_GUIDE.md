# Make Melodex yours

This guide is for listeners who want to explore beyond the first Play button but do not want to write code.

Start with one change. You can leave advanced settings alone until you need them.

## Shape a listening session

On **Home**, try **Comfort**, **Explore**, or **Rediscover**. Choose **Tune it…** for the **Familiar — Adventurous** control.

Use **Keep** and **♥** to guide future sessions. Open the queue and choose **Flow queue** when you want a smoother order. See the [user guide](USER_GUIDE.md) for the everyday controls.

## Work with your collection

**My Music** keeps your local files in place while Melodex organizes them into Albums, Artists, and Tracks.

- **Find missing artwork** looks for album covers.
- **Get artist photos** looks for artist portraits.
- **Tracks → Edit** saves a local correction without changing your audio file or embedded tags.
- **Explore Album Wall** gives you a spatial way to browse and play albums.

See [My Music](MY_MUSIC.md) and [Album Wall](ALBUM_WALL.md) for details.

## Search more sources

Start with **Explore → Search everything**. To add sources or optional extensions, open **Sources & plugins**. You can also add a personal stream URL or manage community packages there.

Melodex's six desktop streaming sources are ready on first launch. Each service hosts its own audio. Read [Music sources](SOURCES.md) before adding a source, and check the source's own terms.

## Explore relationships and routes

**Music Map** shows connections between local tracks. **Plan a route…** opens route planning when you want a more deliberate journey. The **Journeys** page stores reusable recipes and private run history.

## Add optional extras

Lyrics are part of the native Now Playing screen; installed lyric sources feed that same view. You can add visualizer recipes from **Visuals → Add visualizer…**, or install plugins for more sources, artwork, lyrics, recommendations, or context.

- [Plugin Directory](PLUGIN_DIRECTORY.md)
- [Provider and extension installation](PROVIDER_INSTALLATION.md)

## Use an AI tool only if you want one

**Playlists → Paste from AI…** accepts a list copied from ChatGPT or another chat. Melodex parses it on your device; this does not connect an AI account.

If you want a model to control Melodex directly, see the [optional LLM guide](LLM_GUIDE.md). Local playback, Flow, and the features above do not require it.

## Need technical controls?

Turn on the **Power tools** toggle at the bottom of the sidebar when you need provider priority or diagnostics. Use **Sources & plugins** for Bridge setup. For writing providers, plugins, or integrations, go to the [Developer Gateway](DEVELOPERS.md).

See [Privacy](PRIVACY.md) for what stays local and when connected services receive a request.
