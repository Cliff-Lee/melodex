# Privacy

## Stored locally

- music folder locations
- Flow audio fingerprints
- listening history
- completion and skip events
- Love / Keep feedback
- Moments
- saved playlists and Vibes
- provider configuration

## LLM

Nothing is sent to an LLM unless you configure one and submit a prompt. The configured LLM service receives only the context needed for that request.

## Provider Bridge

The Bridge uses a randomly generated bearer token. Anyone with network access to the Bridge and that token can query exposed sources, so keep it private.
