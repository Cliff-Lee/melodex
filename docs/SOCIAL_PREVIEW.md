# GitHub Social Preview

> **Maintainer note.** This page is repository presentation guidance, not product/user documentation.


Recommended canvas: **1280 × 640 px**

Use this composition:

- Large wordmark: **MELODEX**
- Tagline: **Don't shuffle. Flow.**
- One clean crop of the Melodex UI
- Footer line: **Local-first · Open source · Optional AI**
- Keep the background simple and dark enough for the interface crop to stand out.
- Avoid small text; the image will often be shown as a thumbnail.

Upload in:

**GitHub → repository Settings → General → Social preview**

A good source screenshot is `docs/images/play-for-me.png`.
