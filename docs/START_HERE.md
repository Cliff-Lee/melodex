## The shortest possible introduction

1. Install Melodex.
2. Open **Sources**.
3. Choose **Add local folder...**.
4. Select your music folder.
5. Open **My music** and test one track.
6. Open **Play for Me**.
7. Choose a mode, session length and **Familiar - Surprising** level.
8. Press **Build this journey**.

That is enough to start.

## Five controls worth knowing

- **Play for Me** - build a listening session.
- **Flow queue** - resequence the upcoming queue.
- **Keep** - tell Melodex this belongs in your taste.
- **Love** - strong positive feedback.
- **... -> Save Moment** - remember the exact point in a song.

## Add more sources when you want them

Everything beyond local files is optional:

- **User Streams** - direct HTTP(S) audio, internet radio and M3U/M3U8/PLS stream playlists.
- **Jamendo** - reference provider using your own developer client ID.
- **Internet Archive** - official optional `.mdxprovider` for publicly accessible Archive audio.
- **Third-party providers** - compatible packages you choose to trust.
