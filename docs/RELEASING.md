# Releasing Melodex

1. Update `VERSION`.
2. Run the desktop tests and provider SDK tests.
3. Commit.
4. Tag the release, for example:

```bash
git tag v0.1.0
git push origin main --tags
```

The GitHub workflows build native artifacts on their native runners. Code signing/notarisation credentials are optional repository secrets; unsigned artifacts are still useful for development releases.

Expected release artifacts:

- macOS app archive / DMG
- Windows executable / portable ZIP
- Android APK
- Android AAB
- source archive generated by GitHub
