# Parachord-inspired Roadmap Addendum: Rich Now Playing

> **Historical stage snapshot.** This page captures what was implemented/planned at one point during Rich Now Playing development. Later work (including Wikimedia artist visuals and release timelines) superseded some unchecked items below. See [Artist visuals](ARTIST_VISUALS.md) and [Status, stability and trust](developers/00_STATUS_AND_STABILITY.md) for current behavior.


Implemented in this stage:

- [x] metadata separated from playback providers
- [x] MusicBrainz recording/artist/release matching
- [x] Cover Art Archive artwork cache
- [x] embedded/provider/CAA artwork priority
- [x] local `.lrc` synchronized lyrics
- [x] local `.txt` and embedded lyrics
- [x] artist/band relationships and genres/tags
- [x] structured credits where MusicBrainz supplies them
- [x] full Now Playing information page
- [x] artwork-derived UI accent/background

Good follow-ups:

- [ ] Last.fm or ListenBrainz optional enrichment/recommendations
- [ ] Wikimedia/Wikidata artist photographs with attribution
- [ ] waveform seek display
- [ ] spectrum visualizer
- [ ] release timeline / cover-wall browser
- [ ] dedicated lyrics-provider SDK for licensed services
- [ ] volume normalization
